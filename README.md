# Customer Shopping Behavior Analysis

## Project Overview
This project analyzes customer shopping behavior using 3,900 purchase records to identify purchasing patterns, customer segments, revenue trends, and product preferences.

The goal is to generate useful business insights that can help improve customer engagement, sales, and marketing strategies.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Jupyter Notebook
- SQL (PostgreSQL)
- Power BI

## Project Workflow

### 1. Data Preparation using Python
- Loaded the dataset using Pandas.
- Explored the dataset using info() and describe().
- Checked and handled missing values.
- Standardized column names.
- Created age groups.
- Created purchase frequency features.
- Loaded cleaned data into PostgreSQL.

### 2. Data Analysis using SQL
Performed SQL analysis to answer business questions:

1. Revenue generated by male and female customers.
2. High-spending customers who used discounts.
3. Top 5 products based on average review ratings.
4. Comparison of Standard and Express shipping.
5. Subscribers vs. non-subscribers spending.
6. Products with the highest discount rates.
7. Customer segmentation.
8. Top 3 products in each category.
9. Repeat buyers and subscription behavior.
10. Revenue contribution by age group.

### 3. Data Visualization using Power BI
Created an interactive dashboard to present customer shopping insights and trends.

## Business Recommendations
- Improve subscription benefits.
- Introduce customer loyalty programs.
- Optimize discount strategies.
- Promote highly rated and popular products.
- Focus marketing on high-revenue customer segments.
